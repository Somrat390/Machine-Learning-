# Iris Flower Classification

This project is a Machine Learning classification project using the Iris dataset.

The model predicts the species of an iris flower based on:
- sepal length
- sepal width
- petal length
- petal width

## Dataset

The dataset used is the famous Iris dataset from Scikit-learn.

Classes:
- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

1. Load Dataset
2. Data Exploration
3. Data Visualization
4. Feature and Target Selection
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Prediction

## Exploratory Data Analysis

Performed:
- `df.info()`
- `df.describe()`
- Histograms
- Pairplots

Key Findings:
- Petal length and petal width are highly informative features
- Setosa class is clearly separable
- Versicolor and Virginica slightly overlap
